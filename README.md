
# StudyFlow - Mobile App Wireframing

## 1. Project Overview

StudyFlow is a student productivity mobile application designed to help students manage their daily tasks, organize their class schedules, and track their academic progress.

The purpose of this project is to create low-fidelity wireframes that demonstrate the basic layout and navigation of a mobile application.

## 2. Problem Statement

Students often find it difficult to organize assignments, remember upcoming classes, and manage their daily academic responsibilities. StudyFlow aims to provide a simple interface to organize these activities in one place.

## 3. User Research

Basic user needs considered during the design process include:

- Easy access to daily tasks and class schedules.
- A simple way to track assignment completion.
- A clear and easy-to-use interface.
- Quick navigation between different sections.

Note: These needs are initial assumptions for the prototype, not findings from completed user interviews or surveys.

## 4. User Persona

Name: Alex

Age: 19

Occupation: College Student

Goals:
- Organize assignments and academic activities.
- Keep track of upcoming classes.
- Complete tasks on time.

Challenges:
- Forgetting assignment deadlines.
- Managing multiple academic responsibilities.
- Finding it difficult to track daily progress.

Needs:
A simple mobile application that combines task management, class schedules, and progress tracking.

## 5. User Flow

Login -> Home -> View Daily Progress -> Open Tasks -> Add or Complete a Task

Additional navigation:
Home -> Profile -> View Student Details -> Log Out

## 6. Low-Fidelity Wireframes

The prototype includes four screens:

1. Login Screen - Allows users to enter their email and password.
2. Home Screen - Displays daily progress and upcoming classes.
3. Tasks Screen - Displays tasks, checkboxes, and an option to add tasks.
4. Profile Screen - Displays student details and preferences.

The wireframes use grayscale colors, basic shapes, outlined sections, and simple text to focus on structure and usability rather than visual styling.

## 7. Design Thinking Process

### Empathize
Identify students' needs related to academic organization and task management.

### Define
Students need a simple way to manage assignments, schedules, and daily progress.

### Ideate
Plan a mobile application with login, home, tasks, and profile screens.

### Prototype
Build low-fidelity wireframes using HTML and CSS in Visual Studio Code.

### Test
Navigate between screens and test task creation and checkbox interactions. Further feedback from actual student users can be used to improve the design.
